# CherryPick — Personal Art Gallery & Progress Tracker 🍒

**CherryPick** — це веб-орієнтована система для організації художнього портфоліо, обліку часу творчої діяльності та ведення статистики прогресу. Проєкт розроблено як курсову роботу з дисципліни "Веб-технології та веб-дизайн".

## 📋 Основний функціонал

* **🗂 Цифровий архів:** Зберігання та систематизація робіт за статусами, жанрами та стилями.
* **⏱️ Трекінг часу:** Вбудований таймер для фіксації сесій малювання з нотатками.
* **📊 Аналітика:** Теплова карта активності та графіки продуктивності.
* **📚 Колекції:** Групування робіт у мудборди, серії або виставки.
* **📝 Нотатки (Sticky Notes):** Швидкі записи ідей та думок.

## 🛠 Технологічний стек

* **Frontend:** React.js, Tailwind CSS, Recharts, Axios.
* **Backend:** Node.js, Express.js, SQLite3, JWT, Multer.

## 🚀 Встановлення та запуск (Quick Start)

Процес розгортання максимального спрощений. Усі команди виконуються з кореневої папки.

### 1. Завантаження та встановлення
```bash
# Клонування репозиторію
git clone [https://github.com/viktoriasurych/CherryPick.git](https://github.com/viktoriasurych/CherryPick.git)
cd CherryPick

# Встановлення всіх залежностей (клієнт + сервер) однією командою
npm install

# Запуск у режимі розробки
npm run dev

Відкрийте браузер за адресою: http://localhost:5173
